# 🧹 방구석 로또 헌터 3D (Room Lotto Hunter 3D)

가상의 3D 방을 직접 청소하고 정리하면서 숨겨진 로또와 황금 조각을 찾아 부를 축적하는 브라우저 3D 캐주얼 게임입니다.  
별도 빌드나 서버 없이 단일 `index.html` 파일만으로 PC와 모바일에서 바로 실행할 수 있습니다.

## 주요 기능

- **실감 나는 3D 방 청소 & 정리**: 쓰레기는 쓰레기통에 버리고, 책은 책장에 꽂고, 옷은 개서 옷장에 넣으며, 먼지떨이·무선 청소기·물걸레로 가구 먼지·바닥 먼지·커피 얼룩·창문 유리·화분까지 직접 관리합니다.
- **5가지 3D 테마 방 & 집 등급 업그레이드**: 아늑한 자취방, 알록달록 아이방, 중세시대 성, 전설의 쓰레기방, 고풍스러운 도서관 컨셉 전환과 함께 반지하 원룸부터 한강뷰 아파트·스카이 펜트하우스까지 이사할 수 있습니다.
- **즉석 복권 긁기 · 로또 6/45 · 합성 · 더블 찬스**: 은박을 직접 문질러 긁는 즉석 복권·황금 복권(일반 3장 → 황금 1장 합성 지원)과 수동/자동 번호 선택 및 보너스 볼 추첨을 지원하는 6/45 로또, 당첨금 2.2배 더블 찬스를 제공합니다.
- **성장과 엔드게임 루프**: 3D 도구 외형 티어 진화, 로그라이크 3택 1 청소 특전, 럭키 황금 드론, 불로소득 자산·3D 인테리어 배치, 성취·테마 도감, 명예 은퇴(프레스티지 황금 배지)까지 모두 담겨 있습니다.

## 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html`을 웹 브라우저로 열거나 GitHub Pages를 활성화해 바로 플레이할 수 있습니다.

## 단축키

- `1 ~ 5`: 손 정리 / 먼지떨이 / 청소기 / 물걸레 / 행운 돋보기 전환
- `Q / E` 또는 마우스 우클릭 드래그: 3D 시점 회전 (마우스 휠: 줌)
- `X`: 가구 투시 모드 토글
- `B`: 상점·인테리어 서랍 열기/닫기
- `F`: 전체화면 전환
